# Project Set-Up

This chapter will take you through the steps of setting up a project that builds a rust library that interfaces with the Prusa Buddy firmware. We will then use this to show how we have built our de-centralised manufacturing system on top of the the firmware. But you can use this template for building any other rust innovation on top of their firmware.

The chapter is structured as follows:

- Buddy Firmware -- An overview of the buddy firmware stack and (some) of its components.
- Prerequisites -- What you will need in terms of software and hardware to build and flash new firmware onto a Prusa machine (example will be the Prusa Mini)
- Scaffolding -- This section describes the steps to set up a new project that builds a rust library that runs on boot.
