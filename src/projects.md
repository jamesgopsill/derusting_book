# Other Projects


**egcode** [<i class="fa-brands fa-rust"></i>](https://jamesgopsill.github.io/egcode/) [<i class="fa-brands fa-github"></i>](https://github.com/jamesgopsill/egcode)<br/>
Protecting Engineering IP by providing the cryptographic tooling to encrypt and decrypt gcode. The Rust crate is provides `no_std` `async` `streaming` format enabling gcode to be encrypted on desktop devices and decrypted directly by Computer Numerial Controlled (CNC) microcontrollers thereby enabling full end-to-end encryption capability.

**binarygcode** [<i class="fa-brands fa-rust"></i>](https://crates.io/crates/binarygcode) [<i class="fa-brands fa-github"></i>](https://github.com/jamesgopsill/binarygcode)<br/>
A Rust port of the [binary gcode](https://github.com/prusa3d/libbgcode) standard from Prusa.

**meatpack** [<i class="fa-brands fa-rust"></i>](https://crates.io/crates/meatpack) [<i class="fa-brands fa-github"></i>](https://github.com/jamesgopsill/meatpack)<br/>
A Rust port of the [MeatPack](https://github.com/scottmudge/OctoPrint-MeatPack) algorithm used to encode gcode significantly reducing its file size.

**embassy-buddy** [<i class="fa-brands fa-rust"></i>](https://crates.io/crates/embassy_buddy) [<i class="fa-brands fa-github"></i>](https://github.com/jamesgopsill/embassy-buddy)<br/>
